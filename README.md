# node-manager-core

Node Manager Core contains a collection of utilities and scaffolding to create and manage an Ethereum node.

## Contributions

Contributions are welcomed! Please see CONTRIBUTING.md for more details.

## Attribution and License History

Early versions were adapted from a [prototype created by Rocket Pool](https://github.com/ocket-pool/node-manager-core).

As of 2024, this work is now entirely based on work from NodeSet, Inc and community contributors.

In 2026, this repository was relicensed from AGPLv3 to MIT. The main reason for this change is to allow everyone to use and modify Hyperdrive (which uses this project as a library) without any requirement to publicly share their changes. Notably, this is important for NodeSet operators who operate as a business instead of as an individual that may have security concerns with publicizing their changes, since the AGPLv3 license already allowed for individuals to modify for private personal use without sharing.
